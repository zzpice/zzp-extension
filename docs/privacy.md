# 权限与隐私

扩展不申请 API 或主机权限，没有后台、内容脚本、工具栏按钮、快捷键和扩展设置页。它只把新标签页导航到固定的 `https://zzp.moe/`，不读取当前网页、浏览历史、搜索词、收藏、Cookie 或登录凭据。

没有遥测、统计、广告、扩展数据缓存或账户体系；Firefox 数据收集声明为 `none`。不支持隐私浏览窗口。

打开后是 Home 的普通网页，搜索、主题、图标、登录、缓存和同步继续遵循 Home 原有行为。扩展不会代理、复制或清空 Home 的存储、草稿及 D1 数据，也不会修改 assets。旧版扩展的本地残留数据不再被读取或处理；本次升级不执行清理用户数据的迁移。

Firefox 原生更新器连接 GitHub 的 HTTPS 更新清单和签名安装包。维护者签名工作流连接 Mozilla，凭据仅保存于 GitHub Actions Secrets，不进入源码或安装包。
